# AI Prompt Reverse Engineering (提示词反推模块)

本模块专为 TikTok 和 Instagram 爆款短视频与视觉素材打造。通过对优秀的竞品图片或视频进行视觉解构与反推，100% 还原与借鉴流行素材的视觉风格与运镜节奏，沉淀出高效的生图与视频提示词（Prompts）。

## 📁 目录结构
- [图片反推提示词指南](./image-to-prompt.md)：如何将竞品图片视觉解构并转化为高精度的生图/视频提示词。
- [视频反推提示词指南](./video-to-prompt.md)：如何将竞品视频素材拆解并转化为动态运镜与分镜提示词。

## 🎯 核心目标
1. **打造 TikTok/Ins 爆款**：快速解构并复刻流行视觉风格与运镜节奏。
2. **高效反推**：跳过繁琐的测试，直接将优秀素材转化为可用的 AI 生图/视频 Prompt。
3. **提升流量**：为社媒矩阵批量化产出高质量、吸睛的视觉内容。
