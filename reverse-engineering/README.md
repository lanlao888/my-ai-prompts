# AI Prompt Reverse Engineering (提示词反推模块)

本模块专为独立站商品视觉制作、AI 生图及视频生成打造。通过对优秀的竞品图片或视频进行视觉解构与反推，沉淀出高效的生图与视频提示词（Prompts），用于批量化生成高质量商品营销素材。

## 📁 目录结构
- [图片反推提示词指南](./image-to-prompt.md)：如何将商品/场景图转化为高精度生图提示词。
- [视频反推提示词指南](./video-to-prompt.md)：如何将视频素材转化为动态运镜与分镜提示词。

## 🎯 核心目标
1. 统一独立站视觉风格（高端、统一、有吸引力）。
2. 快速复刻爆款商品的视觉呈现效果。
3. 降低提示词调试成本，提升 AI 内容产出效率。
4. 目标：打造 TikTok/Ins 爆款内容，100% 还原与借鉴流行素材的视觉风格与运镜节奏。
