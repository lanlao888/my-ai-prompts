# my-ai-prompts

个人 AI 提示词与知识库，支持跨设备同步与 AI 插件调用。专为电商独立站视觉制作、商品生图与营销视频生成打造。

---

## 📁 目录结构

### 1. 🖼️ [image-prompts/](./image-prompts/)
正向生图提示词库，包含各类高端商品展示、静物摄影及场景构建提示词。
* `luxury-product-photography.md` - 奢品/高端商品商业摄影提示词

### 2. 🎥 [video-prompts/](./video-prompts/)
正向视频生成提示词库，包含动态运镜、分镜脚本及沉浸式氛围视频提示词。
* `immersive-lifestyle.md` - 沉浸式生活方式与动态商品展示

### 3. 🔍 [reverse-engineering/](./reverse-engineering/)
AI 提示词逆向反推工作流，用于将竞品优秀图片/视频反推解析为高精度提示词。
* `image-to-prompt.md` - 图片反推生图指南
* `video-to-prompt.md` - 视频反推动态视频指南
